# Rubinny Screen: privacy

**Draft: requires legal review before publication.** Last updated: November 2026.

Rubinny Screen (the Windows app from the Microsoft Store) is a player for Rubinny, open-source
digital signage. This statement covers the app only.

- **What the app keeps:** the address of the Rubinny server you enter, and a screen token that
  the server issues when an administrator approves the screen. Both stay on the computer.
- **Who it talks to:** only that server, run by your organization (or by whoever runs it for
  you). It sends the server what a screen needs: the screen's status, its resolution, what it
  is showing, and screenshots when an administrator asks for one. The privacy policy of that
  server's operator applies to that data.
- **What it does not do:** no analytics, no advertising, no tracking, no data sent to the
  Rubinny project or to any other party.
- **Microsoft:** the Microsoft Store collects its own data about installations and updates,
  under Microsoft's privacy statement.
- **Removing your data:** uninstalling the app removes the server address and the token from
  the computer. Data held by the server is managed by its operator.

Contact: through the repository, https://github.com/diamondrubinny/freescreensign (Security →
Report a vulnerability for security problems).

## עברית

**טיוטה: דורשת בדיקה משפטית לפני פרסום.**

- **מה האפליקציה שומרת:** כתובת שרת ה-Rubinny שהזנתם, וטוקן מסך שהשרת מנפיק כשמנהל מאשר את המסך. שניהם נשמרים במחשב בלבד.
- **עם מי היא מדברת:** רק עם השרת הזה, שמופעל על ידי הארגון שלכם. היא שולחת לו את מה שמסך צריך: מצב, רזולוציה, מה מוצג, וצילום מסך כשמנהל מבקש. על המידע הזה חלה מדיניות הפרטיות של מפעיל השרת.
- **מה היא לא עושה:** אין אנליטיקה, אין פרסום, אין מעקב, ולא נשלח מידע לפרויקט Rubinny או לגורם אחר.
- **Microsoft:** החנות אוספת מידע משלה על התקנות ועדכונים, לפי הצהרת הפרטיות של Microsoft.
- **מחיקה:** הסרת האפליקציה מוחקת את הכתובת והטוקן מהמחשב. מידע שבשרת מנוהל על ידי מפעיל השרת.
